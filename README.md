# Tiny Task Tide 🫙

A tiny, single-file task tracker where each task you add floats into a jar as a bubble. Tap a bubble to pop it and mark the task done — the water level rises and falls with how many tasks are afloat.

## Features

- Add tasks with the input box or by pressing Enter
- Tap a task bubble to complete (pop) it
- Water level in the jar reflects how many tasks are open
- Tracks a running count of completed tasks
- Tasks and completed count persist in `localStorage`, so they survive a page reload
- "Clear completed history" resets the completed counter

## Usage

Open [`index.html`](index.html) directly in a browser — no build step or server required.
